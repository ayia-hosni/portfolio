● About

I build backend systems that hold up in production.

I design and operate distributed services across Java / Spring Boot, Python / FastAPI and PHP / Laravel. My focus is the parts that decide whether a system survives real traffic: clean service boundaries, event-driven pipelines, idempotent jobs, and state that stays consistent under load.

Day to day that means Kafka and Redis for messaging and coordination, Kubernetes on AWS EKS for delivery, and a Prometheus / Grafana layer so problems show up on a dashboard before they show up in a ticket. I care about CI/CD, observability, and code that the next engineer can actually reason about.
